# Glossary

A quick reference for names you’ll see in Gloam. Looking for instructions?
See [Install](INSTALL.md), [Using Gloam](USING.md) or the [detailed guides](README.md).

## A–F

**Add-ons**
: Emulators, readers and media players that Gloam can launch.
  [Install and update them](guides/WINDOWS_SETUP.md).

**argv / file association**
: A rule that opens a file in the right app and passes that app the selected
  filename. For example, opening a Game Boy ROM starts its configured emulator.
  [Supported apps and file types](guides/EMULATORS.md).

**Banner icon**
: The icon stored inside a DS or DSi title. Some DSi titles include animation.
  It’s separate from cover artwork.

**BIOS / firmware**
: System software an emulator may need. Some emulators include a replacement;
  others need files supplied by you. The setup tool shows each app’s requirements.
  [BIOS guide](guides/ADDONS.md#free-replacements-and-remaining-firmware).

**BOOT.NDS**
: Gloam’s main program on the SD card. A full installation also needs its
  supporting folders. [Installation options](INSTALL.md).

**Cover artwork**
: A picture for a game, album, book or other item. It can differ from the icon
  shown in the browser. [Artwork setup](guides/ITEM_PREFERENCES.md).

**DSiWare**
: Downloadable DSi applications and games. Gloam distinguishes titles installed
  on the console from title files on SD. [Installed DSiWare](guides/INSTALLED_DSIWARE.md).

**Forwarder**
: An optional tile in the DSi Menu that opens Gloam from SD.
  [Forwarder setup](guides/GLOAM_FORWARDER.md).

## G–R

**Homebrew**
: Community-made games and apps. Put games in `/roms/Homebrew Games/` and
  applications in `/apps/`.

**NAND**
: The DSi’s internal storage, where its system apps and installed DSiWare live.

**nds-bootstrap**
: The loading software Gloam uses for DS retail games and supported DSiWare
  files on SD. [Game loading and saves](guides/GAME_LOADING.md).

**ROM**
: A game file opened by its matching console loader or emulator. Supported
  file types are listed in each system folder’s `README.txt`.

## S–Z

**SD root**
: The first level of your SD card, before opening any folder. This is where
  `BOOT.NDS`, `roms`, `apps` and `media` go. [Folder guide](guides/SD_LAYOUT.md).

**Sidecar**
: An extra file beside a title, such as its cover image or optional information.
  [Artwork setup](guides/ITEM_PREFERENCES.md).

**Simple settings lock**
: A configuration option that keeps settings in Simple mode. It’s off by
  default. [Settings and setup](guides/WINDOWS_SETUP.md).

**Slot-1**
: The DSi’s DS cartridge slot. [Launching a cartridge](guides/SLOT1_LAUNCH.md).

**Splash**
: A still image or animation shown during startup. Themes can provide one,
  or you can choose your own. [Startup splashes](guides/STARTUP_SPLASHES.md).

**Staging folder**
: A folder on your computer where SD Setup can prepare an installation before
  you copy it to an SD card.

**Tab**
: A section such as Games, Apps or Media. Folder tabs stay within their assigned
  folder; Files lets you browse the whole SD card. [Custom tabs](guides/TABS.md).

**Unlaunch**
: Boot software that can start Gloam when the DSi powers on.
  [DSi homebrew setup guide](https://dsi.cfw.guide/).
