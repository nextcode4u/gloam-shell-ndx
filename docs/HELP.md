# Need a hand?

## A game or file won't open

For other consoles' games, books or videos, install the matching app through
**Add-ons** in the Windows setup tool. Its list also shows whether a BIOS is needed.

[Emulator and file-type guide](guides/EMULATORS.md) · [BIOS requirements](guides/ADDONS.md#free-replacements-and-remaining-firmware)

## Gloam won't start normally

Hold **SELECT** while starting Gloam to skip custom themes, audio and automatic
launching. This keeps your saved preferences.

## Japanese names show question marks

Update Gloam and its shared files using the Windows setup tool. Replacing
BOOT.NDS alone won't restore missing fonts.

## System Settings or menu return shows a blank screen

On some language-patched consoles, press **A** again after launching.
[Known issues](CURRENT_SUPPORT.md) explains the affected setups.

## Something else?

[Report a problem](https://github.com/nextcode4u/gloam-shell-ndx/issues).
Include your Gloam version, console, how you started it and what happened.
