# Using Gloam

## Add your files

Copy your files to these folders on the SD card:

| Content | Folder |
| --- | --- |
| Games | `/roms/` |
| Homebrew games | `/roms/Homebrew Games/` |
| Apps | `/apps/` |
| Books | `/media/books/` |
| Music | `/media/music/` |
| Videos | `/media/videos/` |

Other consoles' games and media need a compatible emulator or player.
Install one through **Add-ons** in the Windows setup tool.

## Get around

| Button | What it does |
| --- | --- |
| D-pad | Move between items |
| A / B | Open / go back |
| L / R | Switch tabs |
| START | Open settings |
| SELECT | Open options for the selected item |
| Y | Show item details |

Tap an item to select it, then tap again to open it.

## Make it yours

Press **START → Appearance** to change the view, icon size or theme.
Use **SELECT** on a title for favorites, game settings and cheats where available.
