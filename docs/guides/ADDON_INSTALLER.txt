Gloam optional application downloader
=====================================

Run ONE of these scripts on your computer after extracting addons.zip.
They are equivalent; PowerShell does not need Python.
They download the remaining reviewed applications directly from upstream and
stage their pinned runtime files onto an existing SD root or staging folder.
No applications with unconfirmed permission are embedded in these scripts.

Python 3.11+:
  python download-addons.py --list
  python download-addons.py --target E:/ --dry-run
  python download-addons.py --target E:/
  python download-addons.py --target E:/ --only gbarunner3 tuna-vids

PowerShell 5.1+ / PowerShell 7:
  .\download-addons.ps1 -List
  .\download-addons.ps1 -Target E:\ -DryRun
  .\download-addons.ps1 -Target E:\
  .\download-addons.ps1 -Target E:\ -Only gbarunner3,tuna-vids

Check and stage reviewed add-on updates (including bundled applications):
  python download-addons.py --target E:/ --check-updates
  python download-addons.py --target E:/ --update --dry-run
  python download-addons.py --target E:/ --update
  .\download-addons.ps1 -Target E:\ -CheckUpdates
  .\download-addons.ps1 -Target E:\ -Update -DryRun
  .\download-addons.ps1 -Target E:\ -Update

Update checks compare installed executable hashes with the current reviewed
catalog from Gloam's GitHub repository. If unavailable or older, the packaged
pins remain in use. New reviewed pins become available remotely after that
catalog is published. --catalog FILE / -Catalog FILE uses a local reviewed lock
or generated manifest. Offline mode uses packaged pins and cached downloads.

Update mode selects installed apps by default; --only / -Only also permits
staging a selected app into an empty target. Matching binaries are skipped.
Different executables (including custom/other versions) are backed up under
CACHE/previous-files/OLD-SHA256/FILENAME before replacement. Copy a backup back
to its original SD path to restore it. Configs are preserved unless overwrite
is requested. Both SNEmulDS components are selected together.

Add --upstream / -Upstream to an online update check to report other upstream
stable-release tags. They are not automatically installed, and can be older than
pinned prereleases. Only reviewed download/member hashes are staged. GitHub
API errors are reported without concealing the reviewed-file check results.

Use --noncommercial / -Noncommercial to include applications with no-profit
conditions. Existing files (including custom game configs) are kept by default.
Use --overwrite / -Overwrite only when you intend to replace those files.
The scripts do not remove previously installed apps or alter your settings,
associations, ROMs, saves or BIOS. GBARunner3 uses your own /_gba/bios.bin.

Downloads and selected archive members are checked against SHA-256 pins.
A changed or unavailable release stops installation instead of silently switching
versions. Only the named application/config files are staged; no whole-archive
extraction. Completed files remain installed if a later download fails. Re-run
the same command to continue; existing files are preserved.

Cache entries include their content hash to support reused release filenames.
Cache: ~/.gloam-addons-cache on the computer, not the SD card.
Change with --cache / -Cache. Use --offline / -Offline with a populated cache.
Install dry runs make no downloads or writes. Update dry runs can read the
online catalog, but never download runtime files or write SD/cache files.
--list / -List shows available
pins and manual-only apps. Keep downloads.json beside the selected script.

If Windows blocks a downloaded script, inspect it first. A per-process command
can run it without changing the machine's execution policy:
  powershell -NoProfile -ExecutionPolicy Bypass -File .\download-addons.ps1 -Target E:\

Unconfirmed permissions remain unconfirmed; downloading is not a redistribution
grant. Upstream terms and complete source/release links are in the repository:
https://github.com/nextcode4u/gloam-shell-ndx/blob/main/docs/guides/ADDONS.md

DSLibris reader
---------------
The bundled BlocksDS reader and its updater use:
  /_nds/dsi-frontend/plugins/apps/dslibris-blocksds.nds
  /data/dslibris/font/                  (five supplied Liberation Fonts)
  /media/books/                       (your unprotected books/documents)
New reader settings use /data/dslibris/dslibris.xml. Existing legacy settings
remain in use unless a managed settings file exists. No settings or books are
installed by these scripts. Missing reader profiles/fonts are installed during
--update / -Update; edited profiles and fonts are preserved unless overwrite
is explicitly requested. Only the reviewed reader font/profile paths are writable.
The reader integration also carries the paired PicoDriveTWL folder-rule profile
(not the emulator binary). Existing profiles remain untouched by default.
Use --only dslibris / -Only dslibris with the update options to select the reader.
Install the matching Gloam BOOT.NDS before using the shared-extension profiles.
Folder rules route .md in /media/books to DSLibris and in /roms/Genesis to
PicoDriveTWL; elsewhere Gloam asks which registered app to launch. Older Gloam
builds can select the first duplicate extension globally. Merge content_root lines
into preserved/custom profiles when updating; no edited profile is overwritten. OPF/OEB packages must
keep their chapter folders. Generic ZIP files are not associated with a reader;
.fb2.zip is matched specifically. DRM, comic archives and scans without text
are not supported by the text reader.

Hachibitto argv release (download-only; noncommercial opt-in):
  python download-addons.py --target E:/ --only hachibitto --noncommercial
  .\download-addons.ps1 -Target E:\ -Only hachibitto -Noncommercial
Its embedded firmware/asset permissions remain unconfirmed. It is not included
in Gloam binary, source or notice archives; the scripts fetch its fork release.
