# Slot-1 helper

The SD release builder installs the official Simple DS Slot-1 Launcher here.
Source: https://github.com/Lorenzooone/Simple-DS-Slot-1-Launcher

Keep slot1launch.txt with the executable. Matching source is distributed under
`dependencies/` in `source.zip`, alongside `sd.zip`. See
docs/guides/SLOT1_LAUNCH.md for helper selection and attribution. The checked-in template contains notices only.
