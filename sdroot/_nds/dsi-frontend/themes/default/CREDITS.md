# Gloam default splash

Artwork supplied by nextcode4u for Gloam Shell NDX, distributed under the
project's GNU General Public License, version 3 or later. The full license is
included in the release's licenses.zip and source.zip.

The unchanged top/bottom GIF sources and conversion command are retained under
assets/ in the Gloam source repository. splash.gsp contains prepared RGB555
indexed artwork, with lossless per-frame compression, at 256×192 per screen,
64 frames and 20 fps. No third-party theme collection artwork is included.
