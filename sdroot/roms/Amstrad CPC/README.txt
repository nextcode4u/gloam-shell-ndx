Amstrad CPC
========================================

SD folder: /roms/Amstrad CPC/

Content: .dsk, compatible .cpr, .dan

Application: SugarDS

Argv in the audited upstream build: direct.

Firmware: Amstrad CPC firmware and ParaDOS are embedded in the stock binary,
with separate terms; no extra download is needed, but embedding is not a free-
BIOS license.

Add-on package: manual / held; terms: GPL-2.0-or-later code; separately
copyrighted firmware.

Upstream: https://github.com/wavemotion-dave/SugarDS
Release: https://github.com/wavemotion-dave/SugarDS/releases/tag/1.6

The shared .dsk extension defaults to SugarDS. A TI, MSX or CoCo disk is not
CPC content; select the correct application explicitly. Only compatible
CPR/DAN cartridge layouts work.

Keep required companion files and saves together. Other emulator-supported
formats may need its own browser or a per-file application choice. Changing an
extension is not a file-format conversion.

Full setup and compatibility audit:
https://github.com/nextcode4u/gloam-shell-ndx/blob/main/docs/guides/ADDONS.md
