Game Gear
========================================

SD folder: /roms/Game Gear/

Content: .gg

Application: S8DS

Argv in the audited upstream build: direct.

Firmware: Configured SMS/GG/SG-1000 cartridge routes normally bypass BIOS.
Other emulated machines can require their own BIOS selected inside S8DS.

Add-on package: manual / held; terms: Project-wide redistribution grant not
found.

Upstream: https://github.com/FluBBaOfWard/S8DS
Release: https://github.com/FluBBaOfWard/S8DS/releases/tag/v1.1.8

Keep required companion files and saves together. Other emulator-supported
formats may need its own browser or a per-file application choice. Changing an
extension is not a file-format conversion.

Full setup and compatibility audit:
https://github.com/nextcode4u/gloam-shell-ndx/blob/main/docs/guides/ADDONS.md
