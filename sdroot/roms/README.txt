For large sets of loose ROM files, the optional PowerShell File Organizer
Scripts group files into # and A-Z subfolders. Run the alphabetical organizer
on your computer inside a single system folder, such as /roms/Nintendo DS/.
Gloam can browse the resulting folders. Keep multi-file games and emulator
support files in their required layouts.

Organizer and usage:
https://github.com/nextcode4u/PowerShell-File-Organizer-Scripts
