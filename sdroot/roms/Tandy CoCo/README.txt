Tandy CoCo
========================================

SD folder: /roms/Tandy CoCo/

Content: .ccc cartridges, .cas tapes

Application: DracoDS

Argv in the audited upstream build: direct.

Firmware: User supplies dragon32.rom or bas12.rom/extbas11.rom; disk11.rom for
CoCo disks. Look in /roms/bios or beside emulator.

Add-on package: available; terms: MIT base + README noncommercial condition.

Upstream: https://github.com/wavemotion-dave/DracoDS
Release: https://github.com/wavemotion-dave/DracoDS/releases/tag/1.9

Select CoCo in DracoDS machine settings. .dsk is assigned globally to SugarDS,
so use DracoDS itself or a per-file application override for CoCo disks.

Keep required companion files and saves together. Other emulator-supported
formats may need its own browser or a per-file application choice. Changing an
extension is not a file-format conversion.

Full setup and compatibility audit:
https://github.com/nextcode4u/gloam-shell-ndx/blob/main/docs/guides/ADDONS.md
