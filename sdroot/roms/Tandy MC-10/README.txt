Tandy MC-10
========================================

SD folder: /roms/Tandy MC-10/

Content: .c10 tapes; optional Alice .k7 tapes

Application: MicroDS

Argv in the audited upstream build: direct.

Firmware: Requires MC10.BIN or MC10.ROM; optional MCX.BIN/MCX.ROM. Put them in
/roms/bios or beside emulator.

Add-on package: available; terms: MIT base + README noncommercial condition.

Upstream: https://github.com/wavemotion-dave/MicroDS
Release: https://github.com/wavemotion-dave/MicroDS/releases/tag/1.1

Select the appropriate machine in MicroDS. .k7 is for compatible Alice tapes,
not a generic tape format.

Keep required companion files and saves together. Other emulator-supported
formats may need its own browser or a per-file application choice. Changing an
extension is not a file-format conversion.

Full setup and compatibility audit:
https://github.com/nextcode4u/gloam-shell-ndx/blob/main/docs/guides/ADDONS.md
